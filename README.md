# Abuja Global Engineering — HTML, CSS & JavaScript

This is a static front-end prototype. It uses no framework, no build tools and no paid libraries.

## Run it
1. Extract `abuja-global-engineering-html.zip`.
2. Open `index.html` in a browser.
3. For the best testing experience, use a simple local web server or host the folder on an HTTPS static host.

## Included
- Engineering service directory
- Phone sales and phone repair category
- New and second-hand sample spare-parts listings
- Search and condition filters
- Fault-report form
- Learning topics
- Demonstration price catalogue
- Mobile-friendly layout and navigation
- Demo seller listing and account forms

## Important
This is a front-end demo. It does not save listings, authenticate accounts, book real engineers, retrieve live prices, or accept payments. Connect a secure backend before launch. Never put payment secret keys or privileged database keys in browser JavaScript.
